# bee_simulator.py 代码详细解析

这是一个用于模拟蜜蜂导航行为的Python模块，实现了基于光学流动的导航算法。

## 全局变量

```python
n_sensors = 20
directions = np.linspace(-np.pi, np.pi, n_sensors, endpoint=False)
D = np.column_stack((np.cos(directions), np.sin(directions), np.zeros(n_sensors)))
```

- [n_sensors](file://d:\计算神经学\path-Navigation-python3\path-Navigation-python3\bee_simulator.py#L3-L3): 传感器数量，整数类型
- [directions](file://d:\计算神经学\path-Navigation-python3\path-Navigation-python3\bee_simulator.py#L4-L4): 传感器角度分布，numpy数组，形状(20,)，范围[-π, π)
- [D](file://d:\计算神经学\path-Navigation-python3\path-Navigation-python3\bee_simulator.py#L5-L6): 传感器方向向量矩阵，numpy数组，形状(20, 3)，每行表示一个传感器的单位方向向量(x, y, z)

## 函数详解

### 1. [image_motion_flow](file://d:\计算神经学\path-Navigation-python3\path-Navigation-python3\bee_simulator.py#L9-L13)(T, R, D)

计算基于运动的光学流动

**参数**:
- [T](file://d:\计算神经学\path-Navigation-python3\path-Navigation-python3\trials.py#L0-L0): 平移向量，numpy数组，形状(3,)
- `R`: 旋转轴向量，numpy数组，形状(3,)
- [D](file://d:\计算神经学\path-Navigation-python3\path-Navigation-python3\bee_simulator.py#L5-L6): 传感器方向矩阵，numpy数组，形状(n_sensors, 3)

**返回值**: 
- 光流矩阵，numpy数组，形状(n_sensors, 3)
- 每一行表示对应传感器检测到的光流矢量

### 2. [rotary_flow](file://d:\计算神经学\path-Navigation-python3\path-Navigation-python3\bee_simulator.py#L16-L18)(D, A)

计算逆时针旋转产生的光流

**参数**:
- [D](file://d:\计算神经学\path-Navigation-python3\path-Navigation-python3\bee_simulator.py#L5-L6): 传感器方向矩阵，numpy数组，形状(n_sensors, 3)
- `A`: 旋转轴向量，numpy数组，形状(3,)

**返回值**: 
- 旋转光流矩阵，numpy数组，形状(n_sensors, 3)

### 3. [translatory_flow](file://d:\计算神经学\path-Navigation-python3\path-Navigation-python3\bee_simulator.py#L21-L22)(D, A)

计算平移运动产生的光流

**参数**:
- [D](file://d:\计算神经学\path-Navigation-python3\path-Navigation-python3\bee_simulator.py#L5-L6): 传感器方向矩阵，numpy数组，形状(n_sensors, 3)
- `A`: 平移方向向量，numpy数组，形状(3,)

**返回值**: 
- 平移光流矩阵，numpy数组，形状(n_sensors, 3)

### 4. [linear_range_model](file://d:\计算神经学\path-Navigation-python3\path-Navigation-python3\bee_simulator.py#L25-L27)(U, P, w=1.0, n=0.0)

线性范围模型（Franz & Krapp 方程5）

**参数**:
- `U`: 预期光流，numpy数组，形状(n_sensors, 3)
- `P`: 实际光流，numpy数组，形状(n_sensors, 3)
- `w`: 权重系数，默认1.0，标量
- [n](file://d:\计算神经学\path-Navigation-python3\path-Navigation-python3\path.json): 噪声项，默认0.0，标量

**返回值**: 
- 响应值，标量（float）

### 5. [tn_axes](file://d:\计算神经学\path-Navigation-python3\path-Navigation-python3\bee_simulator.py#L30-L34)(heading)

计算TN轴（触角感知方向）

**参数**:
- `heading`: 航向角，标量（弧度）

**返回值**: 
- TN轴向量矩阵，numpy数组，形状(2, 3)
- 第一行：heading - π/4 方向的单位向量
- 第二行：heading + π/4 方向的单位向量

### 6. [get_flow2](file://d:\计算神经学\path-Navigation-python3\path-Navigation-python3\bee_simulator.py#L37-L51)(heading, velocity)

详细版本的光流计算函数

**参数**:
- `heading`: 航向角，标量（弧度）
- `velocity`: 速度向量，numpy数组，形状(2,) 或类似结构

**返回值**: 
- 两个方向的响应值，numpy数组，形状(2,)
- 第一个元素：heading - π/4 方向响应
- 第二个元素：heading + π/4 方向响应

### 7. [get_flow](file://d:\计算神经学\path-Navigation-python3\path-Navigation-python3\bee_simulator.py#L54-L59)(heading, velocity, pref_angle=np.pi/4)

简化版光流计算函数

**参数**:
- `heading`: 航向角，标量（弧度）
- `velocity`: 速度向量，numpy数组，形状(2,)
- `pref_angle`: 偏好角度，默认π/4

**返回值**: 
- 两个方向的投影速度，numpy数组，形状(2,)
- 相当于速度向量在两个偏好方向上的投影

### 8. [rotate](file://d:\计算神经学\path-Navigation-python3\path-Navigation-python3\bee_simulator.py#L62-L64)(theta, r)

绕Z轴旋转后的新航向

**参数**:
- `theta`: 当前航向角，标量（弧度）
- `r`: 旋转角度，标量（弧度）

**返回值**: 
- 新航向角，标量（弧度），范围[-π, π)

### 9. [thrust](file://d:\计算神经学\path-Navigation-python3\path-Navigation-python3\bee_simulator.py#L67-L73)(theta, acceleration)

根据当前航向和加速度计算推力向量

**参数**:
- `theta`: 航向角，标量（弧度）
- `acceleration`: 加速度大小，标量

**返回值**: 
- 推力向量，numpy数组，形状(2,)
- x分量: sin(theta) * acceleration
- y分量: cos(theta) * acceleration

### 10. [get_next_state](file://d:\计算神经学\path-Navigation-python3\path-Navigation-python3\bee_simulator.py#L76-L82)(heading, velocity, rotation, acceleration, drag=0.5)

计算新航向和速度状态

**参数**:
- `heading`: 当前航向角，标量（弧度）
- `velocity`: 当前速度向量，numpy数组，形状(2,)
- `rotation`: 旋转指令，标量（弧度）
- `acceleration`: 加速度指令，标量
- `drag`: 阻尼系数，默认0.5

**返回值**: 
- tuple类型，包含:
  - 新航向角，标量（弧度）
  - 新速度向量，numpy数组，形状(2,)

## 总结

该模块实现了一套完整的蜜蜂视觉导航仿真系统，主要包括：
1. 传感器模型（20个方向传感器）
2. 光学流动计算（平移流、旋转流）
3. 导航决策模型（线性范围模型）
4. 运动控制系统（旋转、推进、阻力）

所有涉及向量运算的函数都返回numpy数组，便于高效数值计算。
